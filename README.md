# 日照復能管理系統

長照日間照顧中心用的復能循環系統：**評估 → 開立復能處方 → 照服員每日執行紀錄 → 再評估 → 修正處方**，並依《115年度臺中市社區式日間照顧長照機構評鑑基準》自動檢核 B1、B3、B5–B11。

## 使用方式
- 直接用 Chrome / Edge 開啟 `index.html`（單一檔案，可離線使用，也可放 GitHub Pages、隨身碟）。
- 第一次開啟：到「設定與備份」填中心名稱、建立工作人員，再到右上角選「目前使用者」。
- 想先試用可「載入示範資料」，之後在設定頁「清除示範資料」。

## 角色與流程
| 角色 | 主要畫面 | 做什麼 |
|---|---|---|
| 治療師／護理師 | 個案與處方 → 進行初評/再評 | 巴氏、IADL、SPMSQ、體能（TUG、30秒坐站、握力、步速、單腳站）、GDS-15、MNA-SF、疼痛、身心社會、有意義活動目標；系統建議問題、處方與轉介 |
| 治療師 | 開立／修正處方 | 問題 → 長短期目標 → 處方項目（36項內建處方庫＋自訂）→ 執行日 → 轉介；修正時保留版本與理由 |
| 照顧服務員 | 今日執行 | 出席、體溫、每項處方按 ✓完成／△部分／✕未執行，可記協助程度、耐受度、觀察；不適會通知治療師 |
| 督導／主任 | 總覽、個案討論會、評鑑與成效 | 再評到期提醒、跨專業討論會（≥3專業、追蹤前次決議）、評鑑自主檢核、成效指標、隨機抽3位列印 |

## 資料與備份（重要）
- 資料只存在**這台電腦的這個瀏覽器**（IndexedDB），不會上傳。清除瀏覽器資料會遺失。
- 請每週在「設定與備份」→「匯出備份」（可加密）。
- 多台平板：各台匯出 → 主電腦「匯入／合併」→ 再匯回各台（同筆資料保留較新版本）。

## 開發
原始碼在 `src/`，修改後執行 `python3 build.py` 產生單一檔 `index.html`。
